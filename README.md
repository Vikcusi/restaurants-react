## Ресторан

Сайт ресторана отображает динамически загружаемый список заведений с возможностью поиска по названию. При нажатии на элемент рейтинга отправляется запрос на его изменение — вся логика обработки реализована в родительском компоненте, что позволяет централизованно управлять данными и мгновенно обновлять интерфейс без перезагрузки страницы.

## Запуск

1. Установить зависимости:

   ```bash
   npm install
   ```

2. Запустить приложение:

   ```bash
   npm run dev
   ```
